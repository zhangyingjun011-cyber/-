InphicBatteryTray9 · 任务栏电量小图标   使用说明
========================================

【适用鼠标】
  英菲克 INPHIC IN9 / IN09：完整支持（专用协议）。
  其它品牌：走通用模式，尝试读取标准 HID 电量，能不能用取决于鼠标本身；
  先用 InphicBatteryTray9.exe --find-battery 看看能不能打印出电量。

【安装】
  1. 把整个文件夹解压到任意位置（不要在压缩包里直接运行）。
  2. 双击 安装.cmd（会装到 %LOCALAPPDATA%\InphicBatteryTray9\ 并设置开机自启）。
  3. 如果 Windows 提示“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”。
  4. 任务栏右下角出现图标。若被收进 ^ 溢出区：点开 ^，把它拖到任务栏上一次。

【使用】
  · 左键点图标：图标闪一下 + 旁边弹 2 秒电量气泡（自动消失）
  · 右键：刷新电量 / 重新扫描 / 提醒开关 / 预览提醒 / 重命名 / 自定义图标 / 开机自启 / 退出
  · 电量 ≤20%：滑出一张无声音的小卡片提醒
  · 默认每 5 分钟自动查一次；“立即刷新电量”可手动更新

【换图标（重点）】
  程序默认是自绘的猫耳能量瓶；想换成自己的形象：
  1. 右键任务栏图标 →「选择自定义图标…」→ 选图片，自动保存并生效；
  2. 或者把图片命名为 icon.png，放到：
       %LOCALAPPDATA%\InphicBatteryTray9\icon.png
     （右键「打开图标文件夹」可直接打开；放 exe 同目录也可以）
  3. 或命令行：InphicBatteryTray9.exe --icon=你的图片.png
  建议：正方形、≥192×192、透明底 PNG、主体居中；删掉 icon.png 即恢复默认。

【常见问题】
  · 看不到图标：先看任务栏的 ^ 溢出区。
  · 读不到电量：命令行运行 InphicBatteryTray9.exe --test 或 --find-battery。
  · 杀毒软件报警：只读取电量、不联网、无遥测；可加白名单。
  · 多只鼠标：只显示最近活跃的一只。
  · 不想要开机自启：右键菜单取消“开机自动启动”。

【卸载】
  双击 卸载.cmd，然后删除本文件夹。
